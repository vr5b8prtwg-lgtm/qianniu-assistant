# 千牛工作台助手（精简版：手动输入型号 + 闲鱼搜索 + 报价）

一个常驻本地的桌面小工具，帮你在销售工控产品时：
手动输入（或从剪贴板提取）客户咨询的型号，自动去**闲鱼网页版**搜索，并把“闲鱼价 × 1.4”的报价文案算好给你复制发送。

> 精简版说明：已移除「自动读取千牛聊天框」功能及其组件（界面自动化、OCR 等），
> 保留手动输入型号 + 闲鱼搜索 + 半自动询价 + 报价的核心流程，体积大幅减小。

> 半自动原则：工具**不会**自动给闲鱼卖家发消息、不会自动下单、不会自动把报价填进千牛。
> 与闲鱼卖家的询价聊天、最终成交价录入仍由你人工完成，避免闲鱼风控封号。

## 功能

1. **型号输入**：手动输入型号，或复制客户消息文字后点「从剪贴板提取」自动识别（内置西门子/三菱/欧姆龙/台达/施耐德/ABB/安川/基恩士/松下/汇川/信捷等品牌正则 + 通用兜底）。
2. **闲鱼自动搜索**：用自动化浏览器打开 goofish.com 搜索该型号，抓取标题/价格/卖家并展示在面板；自动限速、检测验证码并提示你人工处理。
3. **半自动询价**：点「自动填询价消息(不发送)」把“你好，型号这款还有货吗，价格是多少？”自动填进与卖家的聊天框，发送由你手动按回车（找不到输入框时自动复制到剪贴板，粘贴即可），尽量降低风控风险。
4. **报价**：输入与闲鱼卖家谈好的成交价，自动按倍率（默认 1.4）计算并生成报价文案，一键复制。
5. **本地历史**：搜索与报价记录保存在本地 SQLite（data.db），同一型号 24 小时内重复搜索直接读缓存。

## 环境要求

- Windows 10/11
- 千牛工作台（正在运行）
- 首次使用需要联网（安装 Python 与依赖、下载浏览器），之后可离线使用（OCR 为本地模型）
- 需要一个可登录闲鱼的淘宝账号（扫码登录，密码登录风险高，不要用）

## 安装

方式一（推荐，一键脚本）：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_env.ps1
```

方式二（手动）：

1. 安装 Python 3.11 或 3.12（官网下载，勾选 Add to PATH）；
2. 在项目根目录执行：
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m playwright install chromium
   ```

## 使用流程

```powershell
.\.venv\Scripts\python.exe -m app
```

1. 打开千牛工作台，点开客户会话；
2. 在工具面板点**「捕获当前会话」**（或按 F8）读取聊天内容；
3. 面板显示识别出的型号（可手动修改 / 从候选里选）；
4. 点**「在闲鱼搜索当前型号」**，结果列表展示标题/价格/卖家；
5. 首次使用先点**「打开/登录闲鱼」**扫码登录一次，之后会话保持；
6. 人工与闲鱼卖家谈好价格后，在面板输入成交价，点**「生成报价」**再**「复制报价」**，粘贴到千牛发送。

可选：勾选**「自动监听新消息」**后，每隔几秒自动捕获当前会话（建议人工点开要看的会话）。

### 首次闲鱼登录（命令行方式）

```powershell
.\.venv\Scripts\python.exe scripts\login_goofish.py
```

## 配置

首次运行自动生成 `config.json`，可修改：

| 配置项 | 说明 | 默认 |
| --- | --- | --- |
| quote.multiplier | 报价倍率 | 1.4 |
| quote.rounding | 取整方式（round/ceil/floor/none） | round |
| quote.template | 报价文案模板，`{model}` `{price}` 为占位符 | 【{model}】报价 {price} 元，含运费另议 |
| inquiry.message_template | 询价消息模板，`{model}` 为占位符 | 你好，这款商品（{model}）是标价吗？ |
| goofish.min/max_search_interval | 搜索间隔（秒），防风控 | 3 / 6 |
| goofish.user_data_dir | 浏览器登录数据目录 | ./browser_profile |
| goofish.browser_channel | msedge 或 chromium（系统 Edge 优先，避免安全软件拦截） | msedge |
| ocr.engine | rapidocr / disabled | rapidocr |

## 常见问题

- **闲鱼弹滑块验证码**：属正常风控，请在浏览器窗口手动拖动滑块完成，再点一次搜索。不要高频连点。
- **浏览器打开失败**：工具默认用系统 Edge，若仍失败请检查杀毒软件/安全软件是否拦截浏览器（可在 config.json 里切换 goofish.browser_channel 为 msedge 或 chromium）。
- **提示未登录 / 搜索不到商品**：闲鱼未登录时不会返回商品数据。请点「打开/登录闲鱼」在浏览器里扫码登录一次，登录后重新搜索。
- **页面出结果但面板提示失败**：旧版本存在此问题，请重启程序（`run_app.bat`）使用最新代码。
- **搜索结果为空**：工具会保存页面快照到 `page_dump/`，可把快照发给开发者更新解析规则。
